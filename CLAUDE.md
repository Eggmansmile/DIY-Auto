# DIY Auto Project — map for Claude

RC car: ESP32 + TB6612 motor driver, 2 rear motors, servo steering, 2S battery. Everything is generated from code; edit the script, not the output.

Git: public repo github.com/Eggmansmile/DIY-Auto (main, tag `v1`). Video frames/stills, `.venv`, Fritzing parts clone, KiCad `.history` and the third-party servo model are in `.gitignore`. Absolute paths are stripped on commit by the `homepath` clean filter (`.gitattributes` + `.git/config`). Licences: MIT (code), CERN-OHL-P-2.0 (hardware). Local only (gitignored): the old H-bridge set (`*hbrug*`, `test_hbridge`, `rev3.net`), `gen_breadboard.py` + `.kicad_bbrd`, and `CAD/ref/LM2596_module.wrl` (real module for the Blender renders, no licence). README images in `docs/` (crops of `Video/stills/`, kicad-cli PCB renders).

## CAD (SolidCraft master, `Scripts/cad/`, run from that folder)
- Master: `CAD/DIY-Auto.sc`. Part files in `CAD/solidcraft/parts/*.sc`, scripts in `CAD/solidcraft/scripts/`. Master is generated by `Scripts/cad/sc_gen/master.py`. After editing a source part, relink with `component.update_links`.
- `sc_build.py <part>` builds one part from its script, `--pair` the L/R pair (thin design + mirror).
- `export_sc.py --dry` (to `CAD/parts_sc/`) / `--apply` (to `CAD/parts/<n subassembly>/`, +`print/`, rewrites `CAD/manifest.json` + `CAD/BOM.md`); `--manifest` only the manifest/BOM. Non-SolidCraft parts (bolts, motors, servo, PCB) are static STEPs in `CAD/parts`; their metadata lives in `manifest.json`.
- Dimensions: `params.py`; helpers: `lib.py`. Old build123d generators: `archive_build123d/` (see its README), no longer the source.
- `check_all.py` = collision/clearance/design-rule check from the STEPs in `CAD/parts`, run after every `--apply`. `plates.py [p1s|a1mini|h2d...]` → `CAD/plates/*.3mf`. `test_fit.py` = fit test block. `gen_drawing.py` = A3 drawing (from the STEPs). `freecad_assembly.py` = FreeCAD 1.1 assembly.
- Run with `uv run -p 3.12 --with build123d --with trimesh --with networkx --with bd_warehouse --with rectpack --with lxml python <script>`.

## Electronics (`Scripts/`, output in `KiCad/`, `Fritzing/`)
Order: `gen_schematic.py` → `gen_pcb.py` → `route_pcb.py` (Freerouting) → `silk_pcb.py`; gerbers in `KiCad/gerbers/`. `gen_breadboard.py` (checked against the netlist), `gen_fritzing.py` (print version), `gen_fritzing_hbrug.py` (learning version, own H-bridges). How to open the KiCad breadboard: `KiCad/README.md`.
