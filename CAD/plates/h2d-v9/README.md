# v9 plate: H2D, black ASA

Open `DIYAuto_v9_ASA_H2D.3mf` in OrcaSlicer and pick:

- Printer: **Bambu Lab H2D 0.4 nozzle**
- Filament: **Bambu ASA @BBL H2D 0.4 nozzle**
- Process: **DIY-Auto ASA strong @BBL H2D** (user preset: 0.20 mm, 5 walls, 5 top/bottom, 40 % gyroid, tree supports on the build plate only, outer brim, textured PEI)

The 3mf from `plates.py` holds only the parts, no slicer settings. Save it as a project after slicing.
